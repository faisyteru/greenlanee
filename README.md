# GreenLane

Prototipe dashboard B2B untuk memilih, memantau, dan mengevaluasi mitra feeder trucking (first/last mile) berdasarkan cost-to-serve, emisi karbon, dan keandalan pengiriman. Dibuat untuk BMC/BPC ITB Insight 2026.

> Prototipe demo. Seluruh data mitra adalah data ilustratif.

## Fitur

- **Dashboard**: KPI, filter koridor, peringkat mitra teratas, cost-to-serve per mitra, peringatan, rekomendasi
- **Partner Scorecard**: tabel mitra dengan sortir dan filter, detail mitra (radar chart, tren 6 bulan)
- **Ranking (AHP-TOPSIS)**: bobot dapat diubah, ranking dihitung ulang langsung di browser, rincian kontribusi, jejak keputusan
- **Simulasi What-If**: dampak biaya dan emisi jika BBM, volume, mitra, armada, atau moda berubah
- **Peringatan Dini**: pemantauan tren on-time, damage, dan SLA terhadap ambang batas

## Menjalankan

Buka `index.html` di browser, atau jalankan `python3 -m http.server 8000` lalu buka http://localhost:8000
